# Concordia Design Direction

Source reference: https://concordia.ro/

The app should feel connected to Concordia without becoming a marketing website. It is an operational reporting tool, so the interface needs to stay calm, compact, and easy to scan.

## Visual Direction

- Use an institutional blue as the main color for navigation, primary buttons, and active states.
- Use teal/green as the constructive accent for completed, verified, and positive status states.
- Keep surfaces mostly white with a very light blue-gray background.
- Use restrained borders, compact spacing, and 8px or smaller corner radius for work surfaces.
- Use chart colors that are distinct but serious: blue, teal, amber, red-orange, and violet.

## Layout Direction

- No landing-page hero for the working app.
- First screen should remain useful: dashboard cards, expert/PM entry points, recent status, and pending checks.
- Expert screens should prioritize calendar, selected month, activity entry, livrabile, and export.
- PM screens should prioritize verification queues, cross-expert checks, missing documents, and monthly status.

## Copy Direction

- Romanian-first interface.
- Use direct labels: `Dashboard Expert`, `Dashboard PM`, `Pontaj`, `Livrabile`, `Verificări`, `Rapoarte`.
- Avoid explanatory marketing text inside the app; use concise status and action labels.

## Brand Notes From Concordia Site

- Concordia presents itself around business representation, social dialogue, programs, studies, news, events, and member-facing content.
- The website includes project references for `Consolidarea capacității Concordia pentru dialog social`, code `302141`.
- The reporting app should therefore look like a serious internal/project operations surface under the same institutional umbrella.
